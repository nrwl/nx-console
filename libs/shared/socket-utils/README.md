# shared-socket-utils

This library was generated with [Nx](https://nx.dev).

## Running unit tests

Run `nx test shared-socket-utils` to execute the unit tests via [Jest](https://jestjs.io).

## Socket path

`getNxConsoleSocketPath` resolves the socket from `NX_SOCKET_DIR`, then `NX_DAEMON_SOCKET_DIR`, then a hashed directory under the OS temp dir.
